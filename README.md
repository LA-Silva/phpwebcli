# phpwebcli
(POC) browser interactive PHP REPL running entirely from web server without backend runtime or Node.js build step. It pairs the **Uniter** PHP-to-JavaScript runtime (`[https://github.com/asmblah/uniter](https://github.com/asmblah/uniter)`) with **jQuery Terminal** and **PrismJS**  execute PHP statements  browser bridge JavaScript APIs into PHP
